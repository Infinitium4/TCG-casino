# CRS VS MANIFESTANTS - Assets

Structure des ressources du jeu.

buildings/  : Batiments et QG des factions
units/      : Sprites et spritesheets des troupes
vehicles/   : Vehicules
maps/       : Tilesets et cartes
effects/    : Effets visuels
ui/         : Interface et icones
audio/      : Musiques et effets sonores
animations/ : Definitions d'animations
data/       : Donnees statiques du jeu
config/     : Configuration des assets

Formats recommandes :
- PNG transparent : batiments et unites
- JSON : atlas, spritesheets et cartes
- WebP : grandes images statiques
- OGG / MP3 : sons et musiques

Les fichiers doivent etre libres d'utilisation
ou disposer d'une licence compatible.
